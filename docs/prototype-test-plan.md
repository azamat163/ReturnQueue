# Бесплатная проверка пользы

Этот план заменяет проверку оплаты для текущего пользовательского решения.
Исторический validation-plan.md сохраняется как исследование первоначальной монетизации.

1. До теста реализовать и проверить P1 из specs/001-free-return-prototype/tasks.md.
2. Пять американских пользователей iPhone с недавним опытом нескольких возвратов;
   первый тест может начать сам пользователь на собственных примерах.
3. Задания: минимальная запись, очередь по местам, сдача, cash/credit, частичный итог,
   экспорт/восстановление. Записать время, ошибки и необходимость подсказок.
4. После получения сборки наблюдать 14 календарных дней: новое реальное использование,
   новые возвраты у участника и причины неиспользования.
5. Сопоставить с текущими Notes/календарём/магазинами. Не выдавать симпатии за пользу.
6. Результат: улучшить ввод, проверить P2 или сменить гипотезу. Никаких платежных тестов.

Интервью и исходящие сообщения не проведены. Контакты/публикации/расходы требуют
авторизации пользователя. Проверка устройства, пользовательская польза и спецификация
документируются отдельно — готовые требования не означают, что приложение работает.
